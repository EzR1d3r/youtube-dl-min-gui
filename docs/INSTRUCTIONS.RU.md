## Скачивание

1. Вставьте ссылку в "Download link" и нажмите "Link Info" для просмотра форматов.
2. В "Options" укажите параметры: например "-f 137+140", где 137 и 140 — ID
   видео и аудио из таблицы. Для MP3: "--extract-audio --audio-format mp3 --audio-quality 0".
3. Нажмите "Download".

## Описание и настройка

Amanita Downloader — графический интерфейс (GUI) к загрузчику yt-dlp.
Для обработки медиа используется FFmpeg, а для работы загрузчика —
JavaScript runtime, например Deno. Версии этих программ выводятся в консоль
при запуске. Для стабильной работы обновляйте их самостоятельно.

Установите yt-dlp, FFmpeg и JavaScript runtime, например Deno.
При запуске из исходников: "python -m pip install -r requirements.txt".

Скопируйте ".settings.example.json" в ".settings.json" рядом с "app.py" или EXE.
Укажите свои пути; в JSON используйте прямые слеши, например C:/Tools.
Пути к загрузчику, FFmpeg и runtime могут быть абсолютными или относительными
к папке "app.py" (при запуске исходников) либо EXE (в сборке).
Например: "./yt-dlp.exe", "./ffmpeg/bin", "deno:./deno.exe".

- "youtube_dl_path": исполняемый файл загрузчика.
- "ffmpeg_path": папка с FFmpeg и FFprobe.
- "js_runtime_path": runtime и путь, например "deno:C:/Tools/deno/deno.exe".
  Пустая строка оставляет настройки yt-dlp по умолчанию.
- "download_dir" и "options": списки сохранённых папок и наборов опций.
- "cookies": файл cookies в формате Netscape, например "./cookies.txt".
  Путь абсолютный или относительно папки программы; пустая строка отключает опцию.
  Один файл может содержать cookies нескольких сайтов. yt-dlp может обновлять его.
- "colors": правила подсветки, например "mp4+1080p:cyan, ERROR:red".
- "font_name", "font_size", "console_bg", "console_fg": оформление консоли.
- "language": "EN" или "RU". "window_size" сохраняется при закрытии.

## Разделение медиа

Включите "Split media", нажмите "Link Info" и выберите режим:

- "Default": разделение исходных глав в выбранную папку.
- "Extended": обрезка или разделение файла по редактируемым диапазонам.
- "Extended Audio": сохранение MP3-треков с редактируемыми тегами и обложками.

Для файлов без глав создаётся один сегмент на весь файл.
Время задаётся как "HH:MM:SS:CC". Стрелки меняют секунды, Shift — минуты,
Ctrl — десятые доли секунды. "Lock" связывает соседние границы глав.
Режимы Extended сохраняют исходный файл и выводят лог обработки FFmpeg.

## Аудиотеги и обложки

Кнопка "+" в заголовке "Tag" добавляет колонку дополнительного тега:
Artist URL (WOAR), Audio URL (WOAF), Genre, Composer, Comment, Disc, BPM,
Copyright, Publisher или Language. Кнопка "…" применяет значение к выбранным строкам.
Дополнительные теги записываются в MP3; пустое поле убирает соответствующий тег.

В "Extended Audio" кнопка "−" удаляет сегмент, "+" добавляет после него новый:
от конца текущего до начала следующего. После последнего создаётся сегмент
нулевой длины; задайте ему диапазон перед скачиванием. Остальные треки не перенумеровываются.
Кнопка "−" в заголовке "Segments" удаляет все выбранные строки.

Редактируйте Title, Artist, Track, Album, Year и Album Artist.
Track отображается и записывается как "01"; Year — четыре цифры или пустое поле.
Имена файлов: "01 - Artist - Title", либо "01 - Title", если Artist пуст.

Выберите строки слева или нажмите "All". Кнопка "…" у заголовка тега
применяет одно значение к выбранным строкам. Выбор влияет только на правки;
при скачивании обрабатываются все сегменты.

Cover: "<original>", путь к JPEG/PNG/GIF/BMP либо пустое поле.
В окне Cover: "X" убирает обложку, "O" задаёт исходное превью,
"…" открывает выбор файла. Неверная или отсутствующая обложка останавливает обработку.

## Другие элементы и решение проблем

- "Exec": запуск только аргументов из "Options"; "-h" показывает справку загрузчика.
- "Clear output": очистка консоли.
- "Colors": изменение правил подсветки на текущий сеанс.
- Если программа не найдена, проверьте её путь в ".settings.json".
- "Options" разделяет аргументы по пробелам и не обрабатывает кавычки.
  Для путей с пробелами используйте "Save folder".
- Держите "docs/" рядом с EXE для вывода справки при запуске.
