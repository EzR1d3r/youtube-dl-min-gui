# Инструкция

[English version](INSTRUCTIONS.EN.md) · [Описание проекта](../README.md)

## Настройка

Установите совместимый с youtube-dl загрузчик и FFmpeg отдельно. Скопируйте
`.settings.example.json` в `.settings.json` рядом с `app.py` (или собранным EXE)
и исправьте пути перед запуском приложения.

- `youtube_dl_path`: полный путь к исполняемому файлу загрузчика, например yt-dlp.exe.
- `ffmpeg_path`: путь к папке с исполняемыми файлами FFmpeg.
- `download_dir`: непустой список папок сохранения; первая папка выбирается при
  запуске. Пример: `["C:/Downloads/videos", "D:/Music"]`.
- `options`: начальное содержимое поля Options.
- `colors`: правила подсветки консоли через запятую, например
  `mp4+1080p:cyan, m4a:magenta, ERROR:red`.
- `font_name`, `font_size`, `console_bg`, `console_fg`: оформление консоли.
- `language`: `EN` или `RU` для инструкции при запуске; подписи интерфейса
  остаются на английском языке.

В JSON можно использовать прямые слеши (`C:/Downloads`) или экранированные
обратные (`C:\\Downloads`). Если в старых настройках `download_dir` задан строкой,
вручную замените её списком. Автоматической миграции нет.

## Скачивание видео или аудио

1. Вставьте ссылку в **Download link**. Правая кнопка мыши заменяет содержимое
   этого поля текстом из буфера обмена.
2. Нажмите **Link Info**, чтобы получить список доступных форматов видео и аудио.
3. Выберите папку в **Save folder** или введите путь вручную. Маленькая кнопка
   **+** сохраняет введённый путь в выпадающий список. Enter также сохраняет его.
4. Введите нужные аргументы загрузчика в **Options**. Например, `-f 137+140`
   объединяет видео формата 137 и аудио формата 140, если эти коды доступны.
   Коды зависят от ссылки; используйте значения из полученного списка.
5. Задайте шаблон имени в **Title sheme**. Начальное значение — `%(title)s.%(ext)s`.
6. Нажмите **Download** и следите за ходом загрузки и ошибками в консоли.

Выбранная папка перемещается в начало списка и восстанавливается при следующем
запуске. Скачивание также сохраняет новый путь, введённый вручную. Повторные пути
не создают дубликатов. Кнопка **+** сохраняет путь; она не открывает диалог выбора
папки и не создаёт каталог.

Пример Options для извлечения аудио через yt-dlp:
`--extract-audio --audio-format mp3 --audio-quality 0`. Для преобразования нужен
FFmpeg. Доступные аргументы смотрите в справке установленного загрузчика.

## Другие элементы интерфейса

- **Exec** запускает загрузчик только с содержимым **Options**. Ссылка, папка,
  шаблон имени и путь к FFmpeg автоматически не добавляются. Чтобы посмотреть
  справку, введите `-h` и нажмите **Exec**.
- **Clear output** очищает консоль приложения.
- **Colors** задаёт подсветку. Для правила `mp4+1080p:cyan` строка должна содержать
  оба фрагмента, чтобы правило сработало.

История папок сохраняется в `.settings.json`. Изменения остальных полей действуют
в текущем сеансе; для постоянных начальных опций и цветов редактируйте файл
настроек при закрытом приложении. Значение `file_title` сейчас не применяется
к начальному содержимому поля шаблона имени.

## Решение проблем

- Если при запуске не найден исполняемый файл, проверьте `youtube_dl_path`.
- Если не работает объединение или преобразование аудио, проверьте `ffmpeg_path`
  и сообщения загрузчика в консоли.
- Держите папку `docs/` рядом с EXE, чтобы инструкция загружалась при запуске.
- Поле Options разделяет аргументы по пробелам и не обрабатывает кавычки.
  Для папок с пробелами используйте отдельное поле Save folder.

История изменений находится в [CHANGELOG.RU.md](CHANGELOG.RU.md).
