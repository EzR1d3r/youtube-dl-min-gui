# История изменений

## 1.1.0 (В разработке)

- Таблица доступных форматов через "Link Info".
- "Split media" с тремя режимами: "Default" разделяет исходные главы; "Extended" обрезает или разделяет редактируемые временные диапазоны; "Extended Audio" сохраняет MP3-треки с редактируемыми тегами, обложками и массовым редактированием тегов.
- Настройка JavaScript runtime для yt-dlp через "js_runtime_path".
- Обработка пустого буфера при вставке ссылок и лишних пробелов в Options.
- Удаление сохранённых папок и наборов опций кнопкой "−".
- Сохранение размера окна при закрытии и восстановление при запуске.
- Сохранение наборов опций кнопкой "+", выбор из списка и восстановление последнего набора.
- Сохранение папок загрузки кнопкой "+" и выбор из выпадающего списка.
- Восстановление последней выбранной папки при запуске.
- Вывод инструкции и истории изменений на русском или английском при запуске.

## 1.0.1

- Добавлена кнопка "Clear output" для очистки консоли приложения.
- Правая кнопка мыши в "Download link" очищает поле перед вставкой из буфера.
- Ошибки загрузчика перенаправлены в консоль приложения.
